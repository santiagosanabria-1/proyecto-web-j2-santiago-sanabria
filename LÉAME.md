# NEXUS TECH

Revista tecnológica digital — análisis profundos, reseñas honestas y una comunidad apasionada por la tecnología.

## Estructura del proyecto

```
📁 NexusTech/
├── index.html                     # Página de inicio
├── LÉAME.md                       # Documentación
├── activos/
│   ├── css/
│   │   ├── main.css               # Variables, reset, keyframes, utilidades
│   │   ├── layout.css             # Layout: header, hero, grids, footer, sidebar, etc.
│   │   ├── componentes.css        # Componentes: cards, buttons, forms, comments, etc.
│   │   └── responsive.css         # Breakpoints responsive (mobile-first)
│   └── img/                       # Imágenes y recursos gráficos
├── páginas/
│   ├── categorías.html            # Categorías con sidebar y filtros
│   ├── resenas.html               # Reseñas con tabla comparativa
│   ├── comunidad.html             # Foro, FAQ y badges
│   ├── eventos.html               # Eventos (conferencias, talleres)
│   ├── contacto.html              # Formulario de contacto e info
│   └── inteligencia-artificial.html  # Artículo individual
└── articulos/                     # Archivos adicionales
```

## Tecnologías

- HTML5 semántico
- CSS3 modular (Mobile First, BEM)
- Sin frameworks ni librerías externas
- Git Flow con Conventional Commits

## Ramas

- `main` — Versión estable
- `develop` — Integración de características
- `feature/*` — Desarrollo de funcionalidades
